# Excel Sutun Aciklamasi

`title`
Haber basligi.

`summary`
Haber ozeti. Sinirsiz uzayabilir.

`source`
Yayin veya kaynak adi.

`author`
Yazar adi.

`date`
Metin olarak tarih.

`link`
PDF icinde tiklanacak hedef baglanti.

`image_name`
Toplu yuklenen gorsellerden biriyle birebir eslesecek dosya adi.
